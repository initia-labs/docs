## Running the Initia node

Once everything is set up, you can now start to run the Initia node.

```sh
systemctl start initiad
```

Once the process is up and running, you can inspect the logs by using the
`journalctl` command.

```sh
journalctl -f -u initiad.service
```

## Syncing historical blocks

When running nodes for networks that are already live, you first need to sync
and process the historical chain data. You can do this in a few main ways:
snapshot syncing and StateSync.

<Tabs>
  <Tab title="Snapshots">
    A chain snapshot sync works by downloading the entire state of the chain at
    a certain height and then running the node off of that state. Nodes that use
    snapshots usually have more historical transaction and block data compared
    to nodes that use StateSync. However, in exchange, snapshot syncing is
    typically much slower due to more information required to be downloaded.
  </Tab>
  <Tab title="StateSync">
    StateSync directly downloads the application state from other nodes in
    the network. Unlike syncing from a snapshot, StateSync focuses on
    downloading and processing the current state of the chain, ignoring
    historical transactions and blocks. However, in exchange for this,
    state-syncing is typically much faster.
  </Tab>
</Tabs>

You can find snapshot and StateSync providers for Initia on the [Networks page](/resources/developer/initia-l1).
