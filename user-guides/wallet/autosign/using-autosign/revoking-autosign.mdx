---
title: "Revoking Autosign"
---

- Open your wallet Settings → Manage Auto-signing.
- Review all active sessions by app name and domain.
- Revoke any session instantly.
- Set or modify fund/spend limits if applicable.

<Warning>
If an unverified or non-whitelisted domain requests access, the wallet will display a warning and deny activation until you manually approve.
</Warning>
