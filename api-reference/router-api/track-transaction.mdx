---
title: 'Track Transaction'
description: 'Submit a transaction for cross-chain tracking.'
api: 'POST /v2/tx/track'
---

Submits a transaction hash for tracking. Use this after broadcasting a transaction to monitor its progress.

## Request Body

<ParamField body="tx_hash" type="string" required>
  The transaction hash to track.
</ParamField>

<ParamField body="chain_id" type="string" required>
  The chain ID where the transaction was submitted.
</ParamField>

<RequestExample>
```bash cURL
curl -X POST https://router-api.initia.xyz/v2/tx/track \
  -H "Content-Type: application/json" \
  -d '{
    "tx_hash": "ABCDEF1234567890...",
    "chain_id": "interwoven-1"
  }'
```

```javascript JavaScript
const response = await fetch("https://router-api.initia.xyz/v2/tx/track", {
  method: "POST",
  headers: { "Content-Type": "application/json" },
  body: JSON.stringify({
    tx_hash: "ABCDEF1234567890...",
    chain_id: "interwoven-1",
  }),
});
const data = await response.json();
```

```python Python
import requests

response = requests.post(
    "https://router-api.initia.xyz/v2/tx/track",
    json={
        "tx_hash": "ABCDEF1234567890...",
        "chain_id": "interwoven-1",
    },
)
data = response.json()
```
</RequestExample>

<ResponseExample>
```json 200
{
  "tx_hash": "ABCDEF1234567890...",
  "chain_id": "interwoven-1"
}
```
</ResponseExample>
