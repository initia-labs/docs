---
title: 'Deployment info'
description: 'Get deployment metadata and configuration.'
api: 'GET https://router-api.initia.xyz/deployment'
---

## Response

Returns deployment configuration including environment, network type, and version info.

<ResponseExample>
```json 200
{
  "environment": "production",
  "l1_nft_transfer_hook_address": "0x...",
  "network_type": "mainnet",
  "skip_api_url": "https://api.skip.build",
  "blacklist_networks": [],
  "version": {
    "commit_sha": "abc123",
    "tag": "v1.0.0"
  }
}
```
</ResponseExample>

<ResponseField name="environment" type="string">
  Deployment environment (e.g. `production`, `dev`).
</ResponseField>

<ResponseField name="l1_nft_transfer_hook_address" type="string">
  L1 NFT transfer hook contract address.
</ResponseField>

<ResponseField name="network_type" type="string">
  Network type (`mainnet` or `testnet`).
</ResponseField>

<ResponseField name="skip_api_url" type="string">
  Upstream Skip API URL.
</ResponseField>

<ResponseField name="blacklist_networks" type="string[]">
  List of blacklisted network chain IDs.
</ResponseField>

<ResponseField name="version" type="object">
  Version metadata.
  <Expandable title="properties">
    <ResponseField name="commit_sha" type="string">
      Git commit SHA of the deployment.
    </ResponseField>
    <ResponseField name="tag" type="string">
      Release tag.
    </ResponseField>
  </Expandable>
</ResponseField>
