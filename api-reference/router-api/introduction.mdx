The Router API provides cross-chain transfer routing for the Initia ecosystem. It computes optimal routes across IBC, LayerZero, Optimistic bridges, and other pathways, then generates the transaction messages needed to execute transfers.

## Capabilities

- **Asset Discovery** — Query supported fungible assets and chains across Initia and external networks
- **Route Computation** — Find optimal transfer paths between any supported source and destination
- **Transaction Generation** — Get signable transaction messages for computed routes
- **Transaction Tracking** — Monitor cross-chain transfer progress
- **NFT Transfers** — Bridge NFTs across Initia L1 and L2 chains via ICS-721
- **Balance Queries** — Fetch token balances and USD values across multiple chains
