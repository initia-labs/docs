---
title: 'JSON-RPC proxy'
description: 'Proxy JSON-RPC requests to supported Cosmos chains.'
api: 'POST https://router-api.initia.xyz/api/rpc/{chainId}'
---

Forwards validated JSON-RPC requests to the target chain's RPC endpoint. Only supported chain IDs and an allowed list of RPC methods are accepted.

## Path parameters

<ParamField path="chainId" type="string" required>
  Chain ID of the target Cosmos chain.
</ParamField>

## Request body

<ParamField body="id" type="number" required>
  JSON-RPC request ID.
</ParamField>

<ParamField body="method" type="string" required>
  RPC method name. Must be in the allowed methods list.
</ParamField>

<ParamField body="params" type="object" required>
  Method-specific parameters.
</ParamField>

<RequestExample>
```json
{
  "id": 1,
  "method": "abci_query",
  "params": {}
}
```
</RequestExample>

<ResponseExample>
```json 200
{
  "jsonrpc": "2.0",
  "id": 1,
  "result": {}
}
```
</ResponseExample>

<Warning>
  Returns `400 Bad Request` for unsupported chain IDs or disallowed RPC methods.
</Warning>
