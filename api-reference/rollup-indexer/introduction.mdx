---
title: 'Introduction'
description: 'Overview of the Rollup Indexer API for querying indexed rollup data.'
---

All rollups come with a built-in indexer that automatically indexes and stores
all relevant data on the chain. This data is exposed through a REST API
that you can use to query historical and current data, including account
transactions, NFTs owned by an account, and more.

## Base URLs

Each rollup has its own indexer endpoint. Select the appropriate base URL for
the rollup you want to query:

| Rollup | Base URL |
| ------ | -------- |
| evm-1 | `https://rollytics-api-evm-1.anvil.asia-southeast.initia.xyz` |
| move-1 | `https://rollytics-api-move-1.anvil.asia-southeast.initia.xyz` |
| wasm-1 | `https://rollytics-api-wasm-1.anvil.asia-southeast.initia.xyz` |

## Features

- **Transaction queries** — Look up transactions by account address, block
  height, or transaction hash
- **NFT queries** — Retrieve NFT collections and tokens by account or
  collection address
