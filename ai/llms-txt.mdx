The Initia docs provide an `llms.txt` file — a structured text document that gives LLMs a complete index of all documentation pages. This follows the [llms.txt standard](https://llmstxt.org) for making websites more accessible to language models.

## What is llms.txt

The `llms.txt` file is a text document served at the root of the documentation site that lists every page with its title and URL. It gives LLMs a structured map of all available content, making it easy to find relevant information without browsing.

## How to access it

The file is available at:

```
https://docs.initia.xyz/llms.txt
```

You can also access the full-content version that includes the complete text of every page:

```
https://docs.initia.xyz/llms-full.txt
```

## Using llms.txt with AI tools

### Paste into an LLM chat

Copy the contents of `llms.txt` and paste it into your conversation with an LLM to give it an overview of all available Initia documentation. You can then ask the LLM to look up specific topics by following the URLs.

### Load in your IDE

Many AI-powered IDEs and coding agents allow you to add documentation context. You can point them to the `llms.txt` URL:

<CodeGroup>

```txt Cursor
Add https://docs.initia.xyz/llms.txt as a documentation source
in Cursor Settings > Features > Docs
```

```txt Claude
Paste the URL or content of llms.txt into your conversation
as context for the LLM
```

</CodeGroup>

### Use llms-full.txt for deep context

If your LLM has a large enough context window, you can use `llms-full.txt` to load the complete documentation content in a single request. This is useful when you need comprehensive coverage rather than targeted lookups.

<Warning>
  The `llms-full.txt` file contains the full text of every documentation page.
  Check the file size before loading it to ensure it fits within your LLM's
  context window.
</Warning>

## What is included

The `llms.txt` file covers all sections of the Initia documentation:

- **Home** — core concepts, architecture, tokenomics
- **Developers** — tutorials, SDKs, CLIs, contract references
- **Nodes and Rollups** — deployment, indexing, validators
- **InterwovenKit** — frontend integration, hooks, components
- **API Reference** — Router API endpoints
- **Resources** — network info, deployed contracts, security audits
