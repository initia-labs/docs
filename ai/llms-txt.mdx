The Initia docs provide `llms.txt` and `llms-full.txt` files that follow the [llms.txt standard](https://llmstxt.org) for making websites more accessible to language models. These files give LLMs structured context about the documentation so they can generate more accurate responses about Initia.

## llms.txt

The `llms.txt` file is a lightweight index of every page in the Initia documentation. It contains the title and URL of each page, giving LLMs a structured map of all available content.

```
https://docs.initia.xyz/llms.txt
```

Use `llms.txt` when you want to give an LLM a quick overview of what documentation exists without loading the full content. This is useful for:

- Helping an LLM understand the scope of Initia documentation
- Letting an LLM decide which pages to fetch based on a user's question
- Adding lightweight context to a conversation without consuming a large context window

## llms-full.txt

The `llms-full.txt` file contains the complete text of every documentation page in a single file. This gives LLMs the full content of the docs in one request.

```
https://docs.initia.xyz/llms-full.txt
```

Use `llms-full.txt` when you need comprehensive coverage and your LLM has a large enough context window. This is useful for:

- Deep research across multiple documentation topics
- Giving an LLM full context to answer complex questions about Initia
- Pre-loading an AI coding agent with complete Initia knowledge

<Warning>
  The `llms-full.txt` file contains the full text of every documentation page.
  Check the file size before loading it to ensure it fits within your LLM's
  context window.
</Warning>

## Using With AI Tools

### Paste Into an LLM Chat

Copy the contents of `llms.txt` or `llms-full.txt` and paste it into your conversation with an LLM. The LLM can then reference the documentation to answer questions about Initia.

### Load in Your IDE

Many AI-powered IDEs and coding agents allow you to add documentation context. You can point them to the `llms.txt` URL:

<CodeGroup>

```txt Cursor
Add https://docs.initia.xyz/llms.txt as a documentation source
in Cursor Settings > Features > Docs
```

```txt Claude
Paste the URL or content of llms.txt into your conversation
as context for the LLM
```

</CodeGroup>
