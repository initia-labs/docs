The Initia documentation provides a [Model Context Protocol (MCP)](https://modelcontextprotocol.io/) server that allows AI coding agents to semantically search the docs directly from your IDE. Instead of manually copying documentation into your prompts, your agent can query the docs on demand.

## What Is MCP

The Model Context Protocol is an open standard that lets AI applications connect to external data sources and tools. The Initia Docs MCP server exposes a search tool that your AI agent can use to find relevant documentation based on natural language queries.

## Setup

<Tabs>
  <Tab title="Cursor">
    Add the following to your Cursor MCP configuration (`.cursor/mcp.json`):

    ```json
    {
      "mcpServers": {
        "initia-docs": {
          "url": "https://docs.initia.xyz/mcp"
        }
      }
    }
    ```
  </Tab>
  <Tab title="Claude Code">
    Add the MCP server using the Claude Code CLI:

    ```bash
    claude mcp add initia-docs https://docs.initia.xyz/mcp
    ```

    Or add it to your `.mcp.json` configuration:

    ```json
    {
      "mcpServers": {
        "initia-docs": {
          "type": "http",
          "url": "https://docs.initia.xyz/mcp"
        }
      }
    }
    ```
  </Tab>
  <Tab title="Windsurf">
    Add the following to your Windsurf MCP configuration:

    ```json
    {
      "mcpServers": {
        "initia-docs": {
          "serverUrl": "https://docs.initia.xyz/mcp"
        }
      }
    }
    ```
  </Tab>
  <Tab title="VS Code">
    Add the following to your VS Code settings (`.vscode/mcp.json`):

    ```json
    {
      "servers": {
        "initia-docs": {
          "type": "http",
          "url": "https://docs.initia.xyz/mcp"
        }
      }
    }
    ```
  </Tab>
  <Tab title="Other MCP-Compatible Tools">
    For any tool that supports MCP, use the following endpoint:

    ```
    https://docs.initia.xyz/mcp
    ```

    Consult your tool's documentation for how to add an MCP server. The Initia Docs MCP server uses the standard HTTP-based MCP transport.
  </Tab>
</Tabs>

## Mintlify Native MCP

The Initia docs are built with [Mintlify](https://mintlify.com), which provides native MCP support. This means you can also access the MCP server directly from any Initia documentation page using the built-in contextual options. Look for the **MCP**, **Cursor**, or **VS Code** buttons on any page to quickly connect your AI tools to that page's content.

You can also add the Initia Docs MCP server to your IDE using the one-click setup links available on documentation pages.

## How It Works

Once configured, your AI agent gains access to a search tool that queries the Initia documentation. When you ask your agent a question about Initia, it can:

1. **Search** the docs using your natural language query
2. **Retrieve** relevant documentation content
3. **Use** that context to generate accurate responses and code

This means your agent always has access to the latest Initia documentation without you needing to manually copy content into your prompts.

## Example Usage

With the MCP server connected, you can ask your AI agent questions like:

- "How do I deploy a rollup on Initia?"
- "What hooks does InterwovenKit provide?"
- "Show me how to create an ERC20 on MiniEVM."
- "What is the Router API and how do I compute a route?"

Your agent will automatically search the Initia docs and use the results to provide accurate, contextual answers.

## Inline Documentation Access

In addition to the MCP server, Initia documentation pages include inline copy buttons that let you quickly use documentation content with AI tools. Look for the following options on any documentation page:

- **Copy as Markdown** — copy the page content for pasting into an LLM
- **Open in ChatGPT** — open the page content directly in ChatGPT
- **Open in Claude** — open the page content directly in Claude
