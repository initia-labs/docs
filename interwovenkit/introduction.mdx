InterwovenKit is the go-to library for building applications on the Interwoven Stack.

## Core Features

InterwovenKit provides everything you need to build applications on the Interwoven Stack:

<CardGroup cols={2}>
  <Card title="Wallet Connection" icon="wallet">
    Seamless connection to Initia Wallet with account management
  </Card>
  <Card title="Transaction Submission" icon="paper-plane">
    UI-based and programmatic transaction methods
  </Card>
  <Card title="Cross-Chain Bridging" icon="bridge">
    Built-in support for asset bridging between chains
  </Card>
  <Card title="Portfolio Management" icon="chart-bar">
    Access balances, assets, and portfolio data across chains
  </Card>
</CardGroup>
