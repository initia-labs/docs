---
title: DEFAULT_GAS_PRICE_MULTIPLIER
---

## Overview

- Default gas price multiplier used by InterwovenKit when suggesting fees
- Reference this constant when you need to reproduce InterwovenKit's default gas price calculation in custom fee logic

## Quickstart

```ts
import { DEFAULT_GAS_PRICE_MULTIPLIER } from "@initia/interwovenkit-react"

// Use the constant in your fee calculation logic
const gasPriceMultiplier = DEFAULT_GAS_PRICE_MULTIPLIER // 1.05
```


## Value

```ts
const DEFAULT_GAS_PRICE_MULTIPLIER: number // 1.05
```

## Notes

- This multiplier is applied on top of base gas prices when InterwovenKit suggests fees
