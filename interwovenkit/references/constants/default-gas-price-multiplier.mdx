---
title: DEFAULT_GAS_PRICE_MULTIPLIER
---

## Overview

- Default gas price multiplier used internally by InterwovenKit when calculating suggested fees
- Used for non-INIT fee tokens on Layer 1 chains to adjust gas prices
- Reference this constant only if you need to reproduce InterwovenKit's fee calculation logic in custom code

## Quickstart

```ts
import { DEFAULT_GAS_PRICE_MULTIPLIER } from "@initia/interwovenkit-react"

// Reproduce InterwovenKit's fee calculation logic
const adjustedPrice = baseGasPrice * DEFAULT_GAS_PRICE_MULTIPLIER
```


## Value

```ts
const DEFAULT_GAS_PRICE_MULTIPLIER: number // 1.05
```

## Notes

- This constant is primarily for internal use. InterwovenKit applies it automatically when suggesting fees
- Only reference this constant if you're building custom fee calculation logic that needs to match InterwovenKit's behavior
