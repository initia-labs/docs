---
title: DEFAULT_GAS_ADJUSTMENT
---

## Overview

- Default gas adjustment multiplier used by InterwovenKit when estimating gas for transactions
- Used internally by InterwovenKit when `gasAdjustment` is not explicitly provided in transaction requests
- Reference this constant only if you need to explicitly match InterwovenKit's default behavior in custom gas estimation logic

## Quickstart

```ts
import { DEFAULT_GAS_ADJUSTMENT } from "@initia/interwovenkit-react"

// Pass explicit gasAdjustment to match InterwovenKit's default
const { requestTxBlock } = useInterwovenKit()
await requestTxBlock({
  messages: [...],
  gasAdjustment: DEFAULT_GAS_ADJUSTMENT, // Optional: defaults to this value if omitted
})
```

## Value

```ts
const DEFAULT_GAS_ADJUSTMENT: number // 1.4
```

## Notes

- Most users don't need to reference this constant. InterwovenKit uses it automatically when `gasAdjustment` is omitted
- Only reference this constant if you need to explicitly match InterwovenKit's default in custom logic or want to document that you're using the same default
