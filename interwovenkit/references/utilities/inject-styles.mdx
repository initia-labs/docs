title: injectStyles
---

## Overview

- Injects CSS into InterwovenKit's Shadow DOM by appending a `<style>` element
- Useful for loading bundled styles or applying custom styles to the widget without affecting the host app's CSS
- Operates at the DOM level and must be called in a browser environment

## Prerequisites

- Must be called in a browser environment (`document` must exist)
- Client-only (no SSR): Not safe for server-side rendering

## Quickstart

```tsx
"use client"

import { useEffect } from "react"
import { injectStyles } from "@initia/interwovenkit-react"
import stylesText from "@initia/interwovenkit-react/styles.js"

export function App() {
  useEffect(() => {
    injectStyles(stylesText)
  }, [])

  return <div>Your app content</div>
}
```

## API

```ts
function injectStyles(css: string): void
```

Injects the provided CSS string into InterwovenKit's Shadow DOM. The `css` parameter should be a string containing CSS rules. Returns `void`.

## Notes

- Each call appends a new `<style>` element to the Shadow DOM
- This function should generally be called once during app startup (for example, inside a top-level `useEffect`) to avoid injecting duplicate style tags
