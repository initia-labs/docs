## Overview

- RainbowKit wallet that enables social login options (email, Google, X (formerly Twitter)) in your RainbowKit wallets list
- **Social logins only**: This wallet is specifically for social login functionality and does not require `PrivyProvider`

## Prerequisites

- Must be used with RainbowKit `getDefaultConfig` or `createConfig`
- If you need AutoSign or embedded wallet features, use `initiaPrivyWallet` with `PrivyProvider` (see [Provider Setup](../setup/providers.mdx))

## Quickstart

```tsx
import { initiaPrivyWallet } from "@initia/interwovenkit-react"
import { getDefaultConfig, RainbowKitProvider } from "@rainbow-me/rainbowkit"
import { metaMask } from "@rainbow-me/rainbowkit/wallets"
import { WagmiProvider } from "wagmi"

export const rainbowConfig = getDefaultConfig({
  appName: "My dApp",
  wallets: [
    [initiaPrivyWallet], // Social logins
    [metaMask()], // External wallets
  ],
})

export function Providers({ children }: { children: React.ReactNode }) {
  return (
    <WagmiProvider config={rainbowConfig}>
      <RainbowKitProvider>
        {children}
      </RainbowKitProvider>
    </WagmiProvider>
  )
}
```

## Return value

```ts
const initiaPrivyWallet: Wallet
```

Type `Wallet` is from `@rainbow-me/rainbowkit`.

## Notes

- This wallet enables social login options and does not require `PrivyProvider`
- Use alongside other RainbowKit wallets (MetaMask, WalletConnect, etc.) to provide multiple connection options
- Display name appears as "Connect Socials" in wallet selection UIs
- For complete provider setup including `InterwovenKitProvider`, `QueryClientProvider`, and `injectStyles`, see [Provider Setup](../setup/providers.mdx)
