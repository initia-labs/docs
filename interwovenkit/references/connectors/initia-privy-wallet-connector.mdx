## Overview

- Wagmi connector that enables social login options (email, Google, X (formerly Twitter)) in your wagmi connector list
- **Social logins only**: This connector is specifically for social login functionality and does not require `PrivyProvider`

## Prerequisites

- Must be used with wagmi `createConfig`
- If you need AutoSign or embedded wallet features, use `initiaPrivyWalletConnector` with `PrivyProvider` (see [Provider Setup](../setup/providers))

## Quickstart

```tsx
import { createConfig, http, WagmiProvider } from "wagmi"
import { mainnet } from "wagmi/chains"
import { metaMask } from "wagmi/connectors"
import { initiaPrivyWalletConnector } from "@initia/interwovenkit-react"

const wagmiConfig = createConfig({
  connectors: [
    initiaPrivyWalletConnector, // Social logins
    metaMask(), // External wallets
  ],
  chains: [mainnet],
  transports: { [mainnet.id]: http() },
})

export function Providers({ children }: { children: React.ReactNode }) {
  return (
    <WagmiProvider config={wagmiConfig}>
      {children}
    </WagmiProvider>
  )
}
```

## Return value

```ts
const initiaPrivyWalletConnector: Connector
```

Type `Connector` is from `wagmi`.

## Notes

- This connector enables social login options and does not require `PrivyProvider`
- Use alongside other wagmi connectors (MetaMask, WalletConnect, etc.) to provide multiple connection options
- Display name appears as "Connect Socials" in wallet selection UIs
- For complete provider setup including `InterwovenKitProvider`, `QueryClientProvider`, and `injectStyles`, see [Provider Setup](../setup/providers)
