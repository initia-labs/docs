## Overview

- Wagmi connector created from `initiaPrivyWalletOptions` for integrating Privy wallets with wagmi and RainbowKit
- Wraps the Privy wallet into a wagmi `Connector` so it can be used in wagmi and RainbowKit configs
- Use this when you want to include the bundled Initia Privy wallet in your wagmi connector list
- **Config-time only**: This connector can be included in wagmi config without requiring `PrivyProvider` at runtime

## Prerequisites

- Must be used with wagmi `createConfig`
- **Runtime Privy requirement**: `PrivyProvider` is only required if you need AutoSign or embedded wallet features (see [Provider Setup](../setup/providers.mdx))

## Quickstart

```ts
import { createConfig } from "wagmi"
import { initiaPrivyWalletConnector } from "@initia/interwovenkit-react"

const wagmiConfig = createConfig({
  connectors: [initiaPrivyWalletConnector],
  /* your chains and transports */
})
```

## Return value

```ts
const initiaPrivyWalletConnector: Connector
```

Type `Connector` is from `wagmi`.

## Notes

- Use this connector alongside other wagmi connectors in your `createConfig` call
- Uses the shared `initiaPrivyWalletOptions` metadata (name, icon, ID)
- **Config vs runtime**: Including this connector in wagmi config does not require `PrivyProvider` at runtime. `PrivyProvider` is only needed for AutoSign or embedded wallet features
