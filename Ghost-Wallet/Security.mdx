Ghost Wallets are **non-custodial**, hence your funds and private keys remain yours.\
 Security is enforced through multiple layers:

| **Safeguard**            | **Description**                                                                                    |
| :----------------------- | :------------------------------------------------------------------------------------------------- |
| **Domain Verification**  | Only verified and whitelisted app domains can request Ghost Wallet permissions.                    |
| **Time-Limited Keys**    | Session keys automatically expire after the chosen duration.                                       |
| **Granular Permissions** | Apps can only perform the functions you explicitly authorize.                                      |
| **User-Revocable**       | You can revoke access anytime via your wallet settings.                                            |
| **No Custody Risk**      | Private keys are never stored on Initia servers; they remain within Privy’s secure enclave system. |

Ghost Wallets are powered by **Privy**, the same infrastructure trusted by **Stripe**, **Hyperliquid**, and [**Pump.fun**](http://Pump.fun), ensuring battle-tested security standards.
