### **How to Enable Ghost Wallet Mode (example)**

![image.png](/images/image.png)

1. Visit an Initia-based application (e.g., Civitia).
2. Click “Connect Wallet” → “Enable auto-signing.”
3. A permission window appears:
   - Duration (10 min / 1h / 1 day / 1 week / until revoked)
   - Scope (what actions the app can perform)
4. Approve once with your main wallet signature.

Enjoy uninterrupted onchain use, all transactions within that scope will be auto-signed.
