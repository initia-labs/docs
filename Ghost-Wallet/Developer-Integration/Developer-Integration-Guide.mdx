### **Technical Foundations**

Ghost Wallets rely on:

- **Privy Embedded Wallets** — secure, embeddable key management.
- **Cosmos SDK Modules:**
  - **AuthZ**: Grants one account permission to execute specific transactions on behalf of another.
  - **FeeGrant**: Allows one account to pay transaction fees for another.

Together, these replicate **session key functionality** in a **non-EVM**, **multi-VM environment**, ensuring chain-agnostic compatibility.
